# Свояк Online

## Запуск
1. Включи GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
2. Создай отдельный проект в Supabase: https://supabase.com/dashboard (не используй проект магазина).
3. В настройках Supabase найди Project URL и публичный publishable/anon key.
4. Открой сайт и введи URL, публичный ключ и ник. Один игрок нажимает «Создать комнату», второй вводит тот же код и нажимает «Войти по коду».
5. Хост начинает матч, выбирает вопросы; игроки жмут «Я отвечаю». Хост оценивает ответ кнопками «Верно/Неверно».

## Важно
- Прототип использует Supabase Realtime Broadcast/Presence; таблицы SQL не нужны для базовой проверки соединения.
- Публичный ключ допустим в браузере, но **никогда не используй service_role/secret key на сайте**.
- Это ранний прототип: право ответа координируется хостом и не является защищённым турнирным арбитражем. Для стабильного релиза нужны серверная авторизация действий и тесты переподключения.
